# Deep Learning Lab Experiments

Python web app for deep learning lab experiment work using a simple Flask-style project structure.

## Overview

This repository contains a lightweight Python web application with templates and static assets. It is structured for presenting lab experiment work through a browser-based interface.

## Tech Stack

- Python
- HTML templates
- CSS static assets

## Project Structure

```text
app.py
templates/
  index.html
static/
  style.css
```

## Getting Started

Install the required dependencies, then run the app.

```bash
python app.py
```

Before publishing this README, confirm the exact Python dependencies and add them to `requirements.txt`.
